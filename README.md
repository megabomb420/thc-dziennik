# 🌿 THC Dziennik

Prosta, ładna aplikacja **PWA** do zapisywania czasów przyjmowania THC — do samokontroli i redukcji.

## Funkcje

- ⚡ Zapis sesji jednym kliknięciem (albo z własną godziną)
- Metody: 💧 Dab · 💨 Vape · 🌬️ Waporyzator · 🚬 Palenie · 🍪 Edibles · 🧴 Olejek/Tincture
- Opcjonalna ilość (g/mg) i notatka (nastrój, powód)
- 📊 Statystyki: sesje dziś, czas od ostatniej, średni odstęp, wykres 7 dni
- 🎯 Dzienny limit sesji z paskiem postępu (tryb redukcji)
- ⬇ Eksport danych do JSON
- 📱 Działa offline, instalowalna jako PWA, dane tylko lokalnie (localStorage)

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

albo dowolny statyczny serwer, np. `npx serve .`

## Deploy

To czysta statyczna strona — wrzuć na GitHub Pages, Netlify albo Vercel i gotowe.
